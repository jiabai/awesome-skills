# 人味儿写作 · Renwei Writing

改完之后，那个人还在。新写的文章，也要让读者看见一个有观察、有判断、
愿意把理由讲明白的人。人味儿来自说话的位置与思考的过程，不靠故意写糙。

## 先判断任务

| 任务 | 做法 |
|---|---|
| 润色、精简、去 AI 味，未要求换文风 | 以原作者为准，优先做局部修整 |
| 重写、扩写、明确要求换口吻 | 可以调整结构、补足必要的解释与过渡，保留约定的立场和事实 |
| 从素材写观点文章，或参照样文创作 | 读 [文风参考](references/essay-style.md)，学习口吻与论证方式，再按受众和篇幅取舍 |

用户提供新样文时，以新样文校准。本技能里的议论风格适合评论和观点文章，
不应覆盖一封安静的信、一段私人叙述或其他明确的体裁要求。

## 什么是人味儿

先找到三件事，再动笔：

1. **位置。** 谁在说话，他看见了什么，关心谁的处境？原文里的
   "我观察到"可能正是作者的位置。代写时，位置从用户提供的身份、素材和
   写作目的里找；第一人称判断可以用，真实叙述中的第一人称经历要有依据。
2. **代价。** 判断背后有什么观察、细节、因果和取舍？让读者跟得上
   判断怎样得来。事实性内容不能用虚构的亲历、访谈或数字制造真实感。
3. **手迹。** "自己的"、句尾的"呢"、自然的重复、忽长忽短的句子，
   都可能携带作者的叹气、犹豫或笃定。先辨认它们的作用，再决定是否调整。

## 打磨别人文字时

1. **改动与问题相称。** 轻度润色优先少动；指出哪里打绊、含混或重复，
   再修哪里。重写和扩写可以增补必要的内容与过渡，事实性内容仍须有依据。
   改动数量不作为质量指标。
2. **毛边先假设是手迹。** 冗余、口语、不工整的对仗和语气词，
   先看它们是不是这个人说话的样子。删掉以后，说话的人还在吗？
3. **凝练的句子要有来处。** 保住原文有效的比喻、对比和收束句。
   新添的判断句要能从前文推出；只求漂亮、狠或方便截屏的句子，撤回。
4. **改完跑事后检查。** 对照
   [references/post-edit-checklist.md](references/post-edit-checklist.md)，
   检查自己新增或改写的表达。按语境判断修辞的作用，不能按标点或句式
   黑名单机械替换。原文只检查受改动影响的衔接，事实疑点另行提示。
5. **按需要交代改动。** 少量改动可逐处说明；大幅改写按段概括关键变化。
   拿不准的标出来，把否决权留给作者。用户只要正文时，直接交正文。
6. **上限是隐形。** 局部改稿的最好结果，是读者感觉不到你来过。
   清掉绊脚的地方，其他保留；用户要求换文风时，按约定的目标改。

## Gotchas（真实失败案例换来的）

- **越磨越用力是默认失败路径。** "打磨三遍"不等于三遍逐级加工。
  第一遍理顺之后，后两遍可以检查与还原，不必强凑新改动。
- **平直陈述也有力量。** "是 A 和 B 的循环"可能就是观察者的冷静。
  没有表达问题时，不必改成对仗。
- **语气词要听着删。** "呢""吧""了"可能携带叹气、自嘲、犹豫。
  "拯救自己的前额叶呢"里的亲近感，不能只按字数精简掉。
- **抽象词换具体词要克制。** "细小琐碎的事情"换成"小红点"看似
  更有画面，但那是你的画面，不是他的。原词不妨碍理解时，保留作者
  自己的抽象层级。

## 写观点文章时

用口语把复杂问题说透：从具体事实或场景进入，解释机制，再落下判断。
详细手法与样文短例见 [文风参考](references/essay-style.md)。

1. 从素材里找一个真正要回答的问题和一个能支撑的主张。立场要明确，
   判断的力度要跟证据相称，避免一开口就是时代、文明、未来。
2. 把关键机制讲出来：怎么发生，怎样传导，谁得到好处，谁付出代价。
   类比用来解释关系；需要证明的判断仍靠事实与推理。
3. 承认有效的反例或好处，再说明它能回答什么、还不能回答什么。
   矛盾解决不了，可以留着，别为了收尾强行抹平。
4. 解释处允许长句，转折和结论可以短。设问要推动思考，口语要接着说事；
   按主题选择贴切的意象，不逐段复刻样文的口头禅、句式和狠话。
5. 结尾回到人的处境、一个具体判断或可行的下一步。收束后停笔，
   不再另添一段万能展望。新作按检查清单复核全文。

## 事实与口吻的边界

样文是表达参考，不是事实资料库或统一的价值立场。借鉴作者观察问题的方式，
不移植他的履历、个人记忆、政治历史结论或未经核实的数据。

用户明确要求虚构角色、故事或情境时，可以按设定创作，按叙事目的选择口吻，
不套议论结构。保持其虚构属性，不将它冒充作者真实经历或事实性论据。

涉及史料、数字、引语或现实事件时，分清已给事实、可验证出处和作者判断。
需要补充的关键事实先查可靠来源；无法核实时，缩小断言或提示缺口。
纯语言润色不必扩成全文考据，也不能把材料里的口径问题改得更肯定。

## 完成标准与参考

交稿前确认：作者的位置还在；重要判断有依据；句子服务于表达；没有将虚构的
经历或材料冒充真实；体裁、篇幅与用户要求一致。问题已解决就交稿，别为了打磨而打磨。

- [事后检查](references/post-edit-checklist.md)：每次交稿前，检查本次写出的部分。
