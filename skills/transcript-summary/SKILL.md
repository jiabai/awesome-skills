# Transcript Summary

把转写稿（视频/音频逐字稿、演讲、访谈、会议纪要、长篇口语化文本）提炼成两部分产物：一张 Mermaid 思维导图加一篇要点总结。提炼忠实于原文，不脑补事实，结果适合直接展示与复制。

源自 FrameQ 桌面客户端「智能提炼」工作区的总结流程，提示词与产物约束经多轮打磨验证。

## 工作流

```
转写文本 → 第一步：生成 Mermaid 思维导图 → 第二步：生成要点总结 → 交付两份产物
```

两步严格顺序执行：第一步的脑图是第二步总结的输入之一。脑图负责组织逻辑结构，总结负责忠实浓缩要点；脑图不得引入文字稿中没有的事实，总结以文字稿为准、脑图仅辅助。

## 第一步：生成 Mermaid 思维导图

向 LLM 发送以下提示词，把 `{文本}` 替换为完整转写稿，`{字数}` 替换为字符数：

```
# 角色
你是逻辑思维导图整理者。提取文字稿的主线、分支与层级，产出可直接保存为本地的 Mermaid mindmap 源码。

## 输出语言要求
所有用户可见的生成值、Markdown 标题与正文、Mermaid 节点标签均使用简体中文。不要改动 JSON 键名、产物 schema 或 Mermaid 语法。

## 任务
把这段文字稿（约 {字数} 字）整理成清晰的思维导图。

## 生成规则
- 优先提取观点、方法、因果、步骤、冲突、结论与可迁移经验。
- 剔除寒暄、重复、填充词与空洞过渡。
- 顶层节点放核心主题，下层放分支与支撑要点。
- 节点标签要简短，不要写成段落级节点。
- 不要添加文字稿中不存在的事实、数字、人物或结论。

## 输出格式
- 只输出 Mermaid mindmap 源码，不要解释、代码围栏或多余文字。
- 第一行必须是 `mindmap`。
- 遵循 Mermaid 语法。示例：
mindmap
  root((核心主题))
    主要分支
      关键要点

## 文字稿
{文本}
```

### 第一步产物约束
- 输出**仅**为 Mermaid 源码，无 Markdown 围栏、无解释文字。
- 首行必须是 `mindmap`。
- 根节点用 `root((核心主题))` 形式。
- 节点用缩进表示层级，标签简短。
- 若 LLM 输出带代码围栏（如 ```mermaid），剥离围栏后保留纯源码。

## 第二步：生成要点总结

把第一步得到的脑图源码与原始转写稿一起作为输入，发送以下提示词，把 `{转写文本}` 替换为完整转写稿，`{第一步脑图源码}` 替换为第一步产出的 Mermaid 源码：

```
# 角色
你是总结编辑。基于源文字稿与 Mermaid 思维导图，撰写要点总结。

## 输出语言要求
所有用户可见的生成值、Markdown 标题与正文均使用简体中文。不要改动 JSON 键名、产物 schema 或 Mermaid 语法。

## 输入
### 文字稿
{转写文本}

### Mermaid 思维导图
{第一步脑图源码}

## 输出要求
- 只输出 Markdown 总结正文，不要 Mermaid 源码、代码围栏或推理过程。
- 以确切标题 `# 要点总结` 开头。
- 接着用 `## 总览`，随后是 2 到 6 个话题小节，配简洁要点。
- 忠实于文字稿。思维导图可组织逻辑，但不增加任何事实。
- 结果适合直接在界面展示与复制；避免空洞泛泛之谈。
```

### 第二步产物约束
- 输出**仅**为 Markdown 正文，不含 Mermaid 源码、不含代码围栏、不含推理过程。
- 首个标题必须恰好是 `# 要点总结`。
- 第二级首节必须恰好是 `## 总览`。
- 总览之后是 2 到 6 个话题小节（`##` 级），每节配简洁要点。
- 任何事实性内容必须可在文字稿中找到出处；脑图仅用于逻辑组织，不得成为新事实来源。

## 质检要点

完成两步后，按以下清单核验产物：

1. **脑图语法**：首行为 `mindmap`，根节点 `root(())`，缩进层级正确，能在 Mermaid 渲染器正常渲染。
2. **脑图纯净**：无代码围栏、无解释文字、无文字稿中不存在的事实。
3. **总结结构**：`# 要点总结` → `## 总览` → 2 到 6 个话题小节，标题层级正确。
4. **总结纯净**：无 Mermaid 源码、无代码围栏、无推理过程。
5. **忠实性**：总结与脑图中所有事实均可在文字稿找到出处；未脑补数字、人物、结论。
6. **去水**：寒暄、重复、填充词、空洞过渡已剔除。

## 适用与边界

**适用**：视频/音频转写稿、演讲逐字稿、访谈记录、会议纪要、长篇口语化文本的结构化提炼。

**不适用**：
- 需要逐字精校的转写纠错（本技能是提炼，不是校对）。
- 需要外部事实核查或补充背景知识（本技能严格 source-grounded，不引入原文外信息）。
- 需要结构化 JSON 产物（本技能输出 Mermaid 加 Markdown，非 JSON）。
